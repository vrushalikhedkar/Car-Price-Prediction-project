# 🚗 Car Price Prediction using Machine Learning

### 📌 About

A Machine Learning project that predicts the price of a car using the
Decision Tree Regressor algorithm.

#


### 🎯 Objective

The goal of this project is to predict car prices based on features such as:

- Year

- Engine Size

- Mileage

- Horsepower



#



### 📂 Dataset

The dataset contains car-related information and the target variable ```Price```.


**Note**: This is a synthetic practice dataset created for learning
purposes.


#



### 🛠️ Technologies Used

- Python

- Pandas

- NumPy

- Matplotlib

- Scikit-learn

- Jupyter Notebook



### 🤖 Machine Learning Algorithm

**Decision Tree Regressor**

Decision Tree Regressor is a supervised machine learning algorithm used
for predicting continuous values such as car prices.



#



### 🔄 Project Workflow

1. Import required libraries

2. Load the car price dataset

3. Check dataset shape and information

4. Check missing values

5. Check and remove duplicate records if required

6. Visualize Engine Size vs Car Price

7. Separate features (X) and target (y)

8. Split data into training and testing sets

9. Train the Decision Tree Regressor model

10. Predict car prices

11. Evaluate the model using:

- Mean Absolute Error (MAE)

- Mean Squared Error (MSE)

- R² Score

12. Visualize Actual vs Predicted prices

13. Predict the price of a new car
